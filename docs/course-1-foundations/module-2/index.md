# Module 2: Becoming an Effective Project Manager

ဤ Module တွင် ထူးချွန်ထက်မြက်သော Project Manager တစ်ဦးဖြစ်စေရန် မရှိမဖြစ် လိုအပ်သည့် ပင်မစွမ်းရည်များ (Core Skills)၊ အဖွဲ့အစည်းနှင့် လုပ်ဖော်ကိုင်ဖက်များအပေါ် ပေးစွမ်းနိုင်သော သီးခြားတန်ဖိုး (Unique Value)၊ နှင့် ပရောဂျက်အောင်မြင်စေရန် ဦးဆောင်ရမည့် တာဝန်ဝတ္တရားများကို အသေးစိတ် ဆွေးနွေးထားပါသည်။

## 🎯 Module 2 ၏ အဓိက ရည်မှန်းချက်များ (Learning Objectives)

1. **Unique Value of a PM:** Project Manager တစ်ဦးသည် မိမိ၏ အဖွဲ့အစည်းနှင့် လုပ်ငန်းခွင်သို့ ပေးစွမ်းနိုင်သော ထူးခြားသည့် သီးသန့်တန်ဖိုးကို ရှင်းပြနိုင်ခြင်း။
2. **Roles and Responsibilities:** ထိရောက်သော PM တစ်ဦး၏ နေ့စဉ်တာဝန်များနှင့် ဦးဆောင်မှု အခန်းကဏ္ဍများကို စနစ်တကျ ဖော်ပြနိုင်ခြင်း။
3. **Core PM Skills:** အစီအစဉ်ဆွဲခြင်း၊ ပြဿနာဖြေရှင်းခြင်းနှင့် ဆက်သွယ်ညှိနှိုင်းခြင်း အပါအဝင် မရှိမဖြစ် ပင်မ စွမ်းရည်များကို ခွဲခြားသတ်မှတ်နိုင်ခြင်း။
4. **Skills Audit & Growth:** မိမိတွင် ရှိနှင့်ပြီးသား စွမ်းရည်များ (Existing/Transferable skills) ကို သိရှိပြီး အလုပ်သစ်အတွက် လိုအပ်မည့် စွမ်းရည်သစ်များကို စိစစ်ဖော်ထုတ် လေ့လာဆည်းပူးနိုင်ခြင်း။
