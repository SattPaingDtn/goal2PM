# Course 1: Foundations of Project Management

Google Project Management Certificate ၏ ပထမဆုံးနှင့် အခြေခံအကျဆုံး သင်ရိုးဖြစ်ပါသည်။ ဤသင်ရိုးတွင် Project Management ၏ အခြေခံသဘောတရားများ၊ Project Manager တစ်ဦး၏ အခန်းကဏ္ဍနှင့် တာဝန်များ၊ Project ဘဝသံသရာ (Project Life Cycle) နှင့် လုပ်ငန်းခွင်ဖွဲ့စည်းပုံများကို စနစ်တကျ လေ့လာရမည် ဖြစ်ပါသည်။

---
