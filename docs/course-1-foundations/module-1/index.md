# Module 1: Embarking on a Career in Project Management

ဤ Module သည် Project Management လောကသို့ စတင်ခြေလှမ်းသူများအတွက် အခြေခံအုတ်မြစ်ဖြစ်ပါသည်။ နေ့စဉ်ဘဝနှင့် လုပ်ငန်းခွင်အတွင်း Project များကို မည်သို့ခွဲခြားသတ်မှတ်နိုင်သည်၊ Project Manager တစ်ဦး၏ နေ့စဉ်တာဝန်များမှာ အဘယ်နည်း စသည်တို့ကို အဓိကထား သင်ကြားပေးပါသည်။

## 🎯 Module 1 ၏ အဓိက ရည်မှန်းချက်များ (Learning Objectives)
1. **Project** နှင့် **Operations (ပုံမှန်လုပ်ငန်းစဉ်)** အကြား ကွာခြားချက်ကို ရှင်းလင်းစွာ ခွဲခြားနိုင်ခြင်း။
2. Project Manager တစ်ဦး၏ အဓိက တာဝန်များနှင့် မရှိမဖြစ် အရည်အချင်းများကို သိရှိနားလည်ခြင်း။
3. လုပ်ငန်းအမျိုးမျိုးတွင် Project Management ၏ အရေးပါပုံနှင့် တန်ဖိုး (Business Value) ကို ရှင်းပြနိုင်ခြင်း။
