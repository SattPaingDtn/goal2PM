## 📌 ၁။ အနှစ်ချုပ် မှတ်စု (Quick Summary & Key Takeaways)

::: tip 💡 မျက်စိထဲ တစ်ချက်ကြည့်ရုံဖြင့် မှတ်သားနိုင်သော အနှစ်ချုပ်
- **PM သည် ရာထူးတစ်ခုသာမက စွမ်းရည်တစ်ခုလည်းဖြစ်ခြင်း (Position & Skill):** ဤသင်ရိုးသည် Project Manager ရာထူးတစ်ခုတည်းအတွက်သာ မဟုတ်ဘဲ၊ PM စွမ်းရည်လိုအပ်သော အခြား အလုပ်အကိုင် အခွင့်အလမ်းပေါင်းများစွာ (Operations, Coordinator, Specialist စသည်) အတွက်ပါ ပြင်ဆင်ပေးမည် ဖြစ်သည်။
- **Course 1 တွင် အဓိက လေ့လာရမည့် အပိုင်း ၄ ပိုင်း:**
  1. **ပရောဂျက်နှင့် PM ၏ သဘောသဘာဝ:** PM တစ်ဦးတွင် ရှိရမည့် စွမ်းရည်များ (သင်ကိုယ်တိုင် မသိစိတ်မှ သင်ယူပြီးဖြစ်နိုင်သည့် နေ့စဉ်ဘဝ ဥပမာများ)။
  2. **Adding Value (တန်ဖိုး ဖြည့်ဆည်းပေးခြင်း):** ပရောဂျက်များတွင် အမှန်တကယ် အကျိုးသက်ရောက်မှု ရှိစေရန် ဆောင်ရွက်ပုံနှင့် တကယ့် Google ဝန်ထမ်းများ၏ လက်တွေ့ အကြံပြုချက်များ။
  3. **Project Life Cycle (ဘဝသံသရာ အဆင့်များ):** အဆင့်တစ်ခုချင်းစီအလိုက် လုပ်ဆောင်ရမည့် တာဝန်များ (Tasks) နှင့် မတူညီသော ပရောဂျက်များအတွက် ထိရောက်မည့် Methodologies များ ရွေးချယ်ပုံ။
  4. **Organizational Structures & Cultures:** ကုမ္ပဏီအဖွဲ့အစည်းများ၏ ဖွဲ့စည်းပုံနှင့် လုပ်ငန်းခွင် ယဉ်ကျေးမှုများက ပရောဂျက်အပေါ် မည်သို့ လွှမ်းမိုးသက်ရောက်မှု ရှိပုံ။
- **အဓိက အသုံးအနှုန်း:** *"Crank things up a notch"* ဆိုသည်မှာ အရှိန်ကို တစ်ဆင့်မြှင့်တင်လိုက်ကြရအောင် / ပိုမိုစိတ်လှုပ်ရှားဖွယ် အားထည့်လုပ်ဆောင်ကြစို့ဟု အဓိပ္ပာယ်ရသည်။
:::
