## 📌 ၁။ အနှစ်ချုပ် မှတ်စု (Quick Summary & Key Takeaways)

::: tip 💡 မျက်စိထဲ တစ်ချက်ကြည့်ရုံဖြင့် မှတ်သားနိုင်သော အနှစ်ချုပ်
- **သမားရိုးကျမဟုတ်သော ခရီးလမ်း (Non-traditional Path):** X တွင် နာမည်ကြီး တက္ကသိုလ်ဘွဲ့ မရှိပါ။ High school နှင့် College တို့မှ ကျောင်းထွက်ခဲ့သူ (dropout) ဖြစ်ပြီး အမြင့်ဆုံးပညာအရည်အချင်း လက်မှတ်မှာ **GED** သာ ဖြစ်သည်။
- **ကိုယ်တိုင်လေ့လာခြင်းမှ စစ်မှုထမ်းဘဝဆီသို့:** ကျောင်းထွက်ပြီးနောက် ကိုယ်တိုင် coding လေ့လာကာ ဝက်ဘ်ဆိုက်များ ရေးသားခဲ့သော်လည်း ရင့်ကျက်သော လူကြီးတစ်ဦး (mature adult) ဖြစ်လာစေမည့် တာဝန်သိစိတ် လိုအပ်သည်ဟု ယူဆသဖြင့် စစ်တပ်ထဲသို့ ဝင်ရောက်ကာ စစ်မှုထမ်း ၈ နှစ် ဖြတ်သန်းခဲ့သည်။
- **Coding မှ PM သို့ ကူးပြောင်းခြင်း:** စစ်တပ်ပြီးနောက် ကမ္ဘာအနှံ့ အစိုးရများနှင့် ကုမ္ပဏီကြီးများအတွက် App များ ရေးသားပေးခဲ့ပြီး Google သို့ ရောက်ရှိခဲ့သည်။ ကွန်ပျူတာရှေ့တွင် တစ်နေကုန် code ထိုင်ရေးနေရသည့် ဘဝထက်၊ လူများနှင့် ပူးပေါင်းညှိနှိုင်းရသည့် **Program Manager** အခန်းကဏ္ဍသည် သူ့အတွက် ပိုမိုစိန်ခေါ်မှုရှိပြီး ဆွဲဆောင်မှု ကြီးမားခဲ့သည်။
- **PM ဖြစ်လာစေရန် အထောက်အကူပြုခဲ့သည့် စွမ်းရည်များ (Core Success Factors):**
  1. **Personal Accountability (မိမိဘဝအပေါ် တာဝန်ခံမှု):** ကိုယ်ပိုင်အချိန်ဇယားများ ရေးဆွဲ၍ Bass guitar တီးခတ်လေ့ကျင့်ခြင်း စသည့် နေ့စဉ်ဘဝ စည်းကမ်းများ တည်ဆောက်ခြင်း။
  2. **Kinetic Learner (လက်တွေ့လုပ်ဆောင်ရင်း သင်ယူသူ):** စာအုပ်ဖတ်ရုံဖြင့် နားမလည်ဘဲ လက်တွေ့လုပ်ကိုင်ရင်း သင်ယူတတ်သူဖြစ်ရာ PM များထံ သွားရောက်၍ *"ခင်ဗျားတို့ ဒါကို ဘာကြောင့် ဒီလိုလုပ်တာလဲ"* ဟု မေးမြန်းစုံစမ်းခဲ့ခြင်း။
  3. **Natural Calling (လူများကို စုစည်းပေးလိုသော စိတ်ဆန္ဒ):** လူများကို အမိန့်ပေးစေခိုင်းလို၍ မဟုတ်ဘဲ လူအားလုံးကို **တစ်မျက်နှာတည်းပေါ်သို့ ရောက်ရှိစေပြီး (getting everyone on the same page)** ဘုံရည်မှန်းချက်တစ်ခုတည်းဆီသို့ အတူတကွ လျှောက်လှမ်းစေလိုသော ပင်ကိုယ်စိတ်ဆန္ဒ ရှိခြင်း။
- **အဓိက သတိပြုဖွယ်ရာ:** နေ့စဉ်ဘဝ စီမံခန့်ခွဲမှုများကို PM အဖြစ် ပြောင်းလဲအသုံးချရာတွင် ပိုမို၍ **ရည်ရွယ်ချက်ရှိရှိ စနစ်တကျ (more intentional)** ဆောင်ရွက်ရပြီး စာရွက်စာတမ်း မှတ်တမ်းမှတ်ရာများ (paperwork) ပိုမိုပါဝင်လာပါသည်။
:::

**အဖြေ:**  
နေ့စဉ်ဘဝတွင် အသုံးပြုသော စွမ်းရည်များကို PM တွင် အလွယ်တကူ ကူးပြောင်းအသုံးချနိုင်သော်လည်း Professional အဆင့်တွင်-
1. ပိုမို၍ **ရည်ရွယ်ချက်ရှိရှိ စနစ်တကျ စဉ်းစားဆောင်ရွက်ရခြင်း (More intentional)** နှင့်
2. တရားဝင် စာရွက်စာတမ်း မှတ်တမ်းမှတ်ရာများ ပိုမိုပါဝင်လာခြင်း (**More paperwork involved**) တို့ ဖြစ်သည်။
