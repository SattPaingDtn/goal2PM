# Lesson 1.5: What does a project manager do?
*(Project Manager တစ်ဦးသည် နေ့စဉ် မည်သည့်အလုပ်များကို လုပ်ဆောင်ရသနည်း)*

- **Course:** Google Project Management Certificate - Course 1: Foundations of Project Management
- **Module:** Module 1 - Embarking on a career in project management
- **Speaker:** Emilio (Program Manager on Responsible Innovation at Google)
- **Topic:** Day-to-day responsibilities, Adding value, Planning & organizing, Managing tasks, and Budgeting

---

## 📌 ၁။ အနှစ်ချုပ် မှတ်စု (Quick Summary & Key Takeaways)

::: tip 💡 မျက်စိထဲ တစ်ချက်ကြည့်ရုံဖြင့် မှတ်သားနိုင်သော အနှစ်ချုပ်
- **တန်ဖိုးဖန်တီးပေးခြင်း (Adding Value):** ပရောဂျက်တစ်ခု၏ အဆုံးစွန်ရလဒ်သည် ကုမ္ပဏီ/အဖွဲ့အစည်းအတွက် အကျိုးအမြတ် သို့မဟုတ် တန်ဖိုး (Value) အမှန်တကယ် ဖြစ်ထွန်းစေရမည်။ 
  - သုံးစွဲသူများအတွက် ဝန်ဆောင်မှုအသစ် ထုတ်လုပ်ပေးခြင်း (New service)
  - ရှိပြီးသား ဝန်ဆောင်မှုကို သုံးစွဲသူစိတ်ကြိုက် ပြင်ဆင်မွမ်းမံပေးခြင်း (Modifying an existing service)
- **လုပ်ငန်းနယ်ပယ်အလိုက် ကွဲပြားမှု (Context Matters):** အဆောက်အအုံအသစ် ဆောက်လုပ်ခြင်း၊ ပြန်ပြည့်မြဲစွမ်းအင် Startup တစ်ခုတွင် ဦးဆောင်ခြင်း၊ သို့မဟုတ် ကိုယ်ပိုင် Event Management လုပ်ငန်း စတင်ခြင်း စသည်ဖြင့် လုပ်ငန်းအမျိုးအစားပေါ်မူတည်၍ နေ့စဉ်တာဝန်များ ကွဲပြားနိုင်သည်။
- **PM တစ်ဦး၏ အဓိက နေ့စဉ်မဏ္ဍိုင် (၃) ရပ် (3 Daily Core Responsibilities):**
  1. **Planning & Organizing (အစီအစဉ်ရေးဆွဲခြင်းနှင့် စနစ်တကျစီစဉ်ခြင်း):** 
     - Teammates များနှင့် ဖောက်သည်များထံမှ လိုအပ်ချက်များ မေးမြန်းစုံစမ်းခြင်း (Gathering requirements via kickoff meetings or surveys)။
     - လူတိုင်း ရည်မှန်းချက် တစ်သားတည်းဖြစ်ပြီး လုပ်ငန်းများ ချောမွေ့စွာ ရှေ့ဆက်နိုင်စေရန် **Project Plan** ရေးဆွဲခြင်း။
  2. **Managing Tasks (လုပ်ငန်းတာဝန်များကို စီမံခန့်ခွဲခြင်း):** 
     - ပရောဂျက် စတင်လည်ပတ်သည်နှင့် အဖွဲ့ဝင်များ၏ Tasks များကို စီမံခန့်ခွဲပေးခြင်း။
     - အရေးပါသော မှတ်တိုင်များ (Key milestones) ကို အဖွဲ့နှင့် ဖောက်သည်များထံ ပုံမှန် အသိပေး အစီရင်ခံခြင်း။
  3. **Budgeting & Controlling Costs (ဘတ်ဂျက်နှင့် ကုန်ကျစရိတ် ထိန်းချုပ်ခြင်း):** 
     - အစီအစဉ်များ ပြောင်းလဲခြင်းကြောင့် မမျှော်လင့်ထားသော ကုန်ကျစရိတ်များ (Unexpected costs) ပေါ်ပေါက်လာပါက ဘတ်ဂျက်ဘောင်မကျော်လွန်စေရန် စဉ်ဆက်မပြတ် ထိန်းကျောင်းရခြင်း။
- **အကောင်းဆုံး ခံစားချက် (The Rewarding Part):** ကိရိယာများ (tools)၊ နည်းပညာများနှင့် လုပ်ထုံးလုပ်နည်းများကို နေ့စဉ် မတူကွဲပြားစွာ အသုံးချရသဖြင့် ပျင်းစရာ လုံးဝမရှိပါ။ အထူးသဖြင့် **ဘာမှမရှိရာမှ အရာတစ်ခုကို အခြေခံမှစတင်၍ ဖန်တီးတည်ဆောက်ရခြင်း (Creating something from nothing, working from the ground up)** သည် အလွန်ကျေနပ်နှစ်သိမ့်ဖွယ်ရာ ကောင်းလှပါသည်။
:::

အချုပ်အားဖြင့်ဆိုရသော် မည်သည့်လုပ်ငန်းတာဝန်ဖြစ်စေ အချိန်မီနှင့် ဘတ်ဂျက်အတွင်း ပြီးစီးပြီး စီးပွားရေးရလဒ် အမှန်တကယ်ထွက်ပေါ်စေခြင်းသည် တန်ဖိုးဖန်တီးခြင်း ဖြစ်သည်။
:::

::: details ❓ မေးခွန်း (၂): PM တစ်ဦး၏ နေ့စဉ် တာဝန်ကြီး (၃) ရပ်မှာ အဘယ်နည်း?
**အဖြေ:**  
1. **Planning and organizing:** လိုအပ်ချက်များ မေးမြန်းစုံစမ်းခြင်း (Gathering requirements)၊ Kickoff meeting များပြုလုပ်ခြင်းနှင့် Project Plan ရေးဆွဲခြင်း။
2. **Managing tasks:** အဖွဲ့ဝင်များ၏ လုပ်ငန်းတာဝန်များကို စီမံခန့်ခွဲပေးခြင်းနှင့် အဓိက Milestone များကို အဖွဲ့သားများနှင့် ဖောက်သည်များထံ ပုံမှန်အသိပေးခြင်း။
3. **Budgeting and controlling costs:** မမျှော်လင့်ထားသော ကုန်ကျစရိတ်များကို စောင့်ကြည့်ပြီး သတ်မှတ်ဘတ်ဂျက်ဘောင်အတွင်း ရှိနေစေရန် ထိန်းကျောင်းခြင်း။
:::

::: details ❓ မေးခွန်း (၃): "There's never a dull moment" ဟု Emilio က PM အလုပ်ကို အဘယ်ကြောင့် တင်စားပြောဆိုခဲ့သနည်း?
**အဖြေ:**  
Project Manager များသည် နေ့စဉ်ရက်ဆက် မတူညီသော ကိရိယာများ (tools)၊ နည်းစနစ်များ (techniques) နှင့် လုပ်ထုံးလုပ်နည်းများ (methodologies) ကို အခြေအနေအလိုက် ပြောင်းလဲအသုံးပြုနေရသောကြောင့် ဖြစ်ပါသည်။ ပျင်းစရာ အချိန်ဟူ၍ လုံးဝမရှိဘဲ နေ့စဉ် စိန်ခေါ်မှုအသစ်များဖြင့် စိတ်လှုပ်ရှားဖွယ် ကောင်းလှပါသည်။
:::
